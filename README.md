# Student Study & Task Manager

## 1. Project Overview

Student Study & Task Manager is a beginner-friendly Python application designed to help students organize their academic activities in one place.

The application allows students to manage their tasks, record study sessions, store subject marks, and view an overall progress summary.

The project is developed using basic Python programming concepts such as variables, input/output, conditional statements, loops, lists, dictionaries, functions, file handling, and JSON data storage.

---

## 2. Problem Statement

Students often need to manage different academic activities such as assignments, study time, and examination marks separately.

This project provides a simple console-based system that combines these activities into one application.

The system helps students:

- Organize academic tasks
- Record study time
- Store subject marks
- Calculate average marks
- View an overall progress summary

---

## 3. Objectives

The main objectives of the project are:

1. To create a simple student task management system.
2. To record and display study sessions.
3. To store and calculate subject marks.
4. To provide a progress dashboard.
5. To demonstrate basic Python programming concepts.
6. To store data using JSON files.
7. To implement input validation and basic error handling.
8. To organize the program into multiple Python modules.

---

## 4. Main Features

### Task Manager

The Task Manager allows the user to:

- Add tasks
- View tasks
- Mark tasks as completed
- Delete tasks

### Study Tracker

The Study Tracker allows the user to:

- Add study sessions
- View study sessions
- Calculate total study time

### Marks Manager

The Marks Manager allows the user to:

- Add subject marks
- View marks
- Calculate average marks
- Validate marks between 0 and 100

### Progress Dashboard

The Progress Dashboard displays:

- Total number of tasks
- Completed tasks
- Pending tasks
- Total study time
- Number of subjects recorded
- Average marks
